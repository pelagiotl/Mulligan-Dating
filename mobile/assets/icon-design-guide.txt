MULLIGAN APP ICON - DESIGN GUIDE
=================================

SIZE: 1024x1024 pixels
FORMAT: PNG (no transparency)

DESIGN OPTION 1: Simple Heart
- Background: #8B1538 (burgundy)
- White heart icon in center
- Clean, minimalist

DESIGN OPTION 2: Card/Heart Combo  
- White background
- Burgundy heart (#8B1538) with playing card suit element
- Represents "second chance" concept

DESIGN OPTION 3: Letter "M"
- Burgundy background (#8B1538)
- White "M" letterform styled as a heart shape
- Modern, brandable

RECOMMENDED:
Option 1 or 3 for simplicity and recognizability

TOOLS:
- Use Figma (free) - create 1024x1024 artboard
- Or Canva - use App Icon template
- Export as PNG, save to: mobile/assets/icon.png

ANDROID ADAPTIVE ICON (adaptive-icon.png)
-----------------------------------------
Android uses the SAME design as iOS (icon.png) but only shows the inner ~66% as a circle.
Content outside this zone gets cut off on some launchers.

We generate adaptive-icon.png from icon.png so both platforms use the same artwork:
- Run: node mobile/scripts/generate-adaptive-icon-from-icon.js
- The script scales icon.png to 66% and centers it on a 1024x1024 transparent canvas.
- Android foreground = adaptive-icon.png; background = app.json adaptiveIcon.backgroundColor (#8B1538).

No manual design needed: keep using icon.png for iOS; regenerate adaptive-icon.png whenever
you change icon.png so Android matches and is not cut off.
