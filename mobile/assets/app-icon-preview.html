Mulligan App Icon (1024×1024)

To Convert to PNG:

  1. Option 1 - Online: Go to CloudConvert or ConvertIO, upload app-icon.svg, set size to 1024×1024, convert
  2. Option 2 - macOS Preview: Open app-icon.svg in Preview app, File → Export, choose PNG, set size to 1024×1024
  3. Option 3 - Canva/Figma: Import the SVG, export as PNG at 1024×1024
