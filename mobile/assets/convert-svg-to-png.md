# Convert SVG to PNG - Quick Guide

## Method 1: Online Converter (Easiest - Recommended)

1. Go to: **https://cloudconvert.com/svg-to-png**
2. Click "Select File" and choose: `app-icon-option-4.svg`
3. Click "Show advanced options"
4. Set:
   - Width: **1024**
   - Height: **1024**
5. Click "Convert"
6. Download the PNG file
7. Rename it to `icon.png` and save it in the `mobile/assets/` folder

## Method 2: Using macOS Safari + Preview

1. Open `app-icon-option-4.svg` in Safari (drag and drop the file into Safari)
2. Press `Cmd + Shift + 4` to take a screenshot, OR
3. Right-click the icon → "Save Image As..." → Save as PNG
4. Open the PNG in Preview
5. Tools → Adjust Size → Set to 1024x1024 pixels
6. Save as `icon.png` in `mobile/assets/` folder

## Method 3: Using Figma (Free)

1. Go to figma.com and create a free account
2. Create a new file
3. Create a 1024x1024 frame
4. File → Import → Select `app-icon-option-4.svg`
5. Select the imported icon
6. Right-click → Export → PNG → 1x
7. Save as `icon.png` in `mobile/assets/` folder

## Method 4: Quick Online Tool

Go to: **https://svgtopng.com/**
- Upload `app-icon-option-4.svg`
- Set size: 1024x1024
- Download and save as `icon.png`
