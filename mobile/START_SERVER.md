# 🚀 Start Development Server

## Quick Start

Open a **new terminal window** and run:

```bash
cd /Users/code404/Desktop/Mulligan-Dating/mobile
npx expo start
```

## What You'll See

1. **Metro bundler** will start
2. A **QR code** will appear
3. Options to press:
   - Press `i` - Open iOS Simulator
   - Press `a` - Open Android Emulator  
   - Press `w` - Open in web browser

## If Port is Busy

If you see "Port 8081 is running", use a different port:

```bash
npx expo start --port 8082
```

## Troubleshooting

**If you see errors:**
- Make sure you're in the `mobile/` directory
- Try: `npm install` again
- Check that Xcode is installed (for iOS Simulator)

**To stop the server:**
- Press `Ctrl+C` in the terminal
