# Mulligan App Icon & Logo Specifications

## App Icon Requirements

### Technical Specs:
- **Size**: 1024x1024 pixels
- **Format**: PNG (no transparency/alpha channel)
- **Color Space**: sRGB
- **Background**: Solid color (no transparency)

### Design Suggestions:
1. **Main Element**: Heart or card symbol (mulligan = second chance)
2. **Colors**: 
   - Primary: #8B1538 (Mulligan burgundy/red)
   - Accent: White or light pink
3. **Style**: Simple, clean, recognizable at small sizes
4. **Background**: Solid color (burgundy or white)

### Tools to Create Icon:
1. **Figma** (free): https://figma.com
   - Create 1024x1024 design
   - Export as PNG
2. **Canva** (free): https://canva.com
   - Search "App Icon" template
   - Customize with Mulligan branding
3. **Adobe Illustrator/Photoshop** (if you have it)
4. **Online Icon Generators**:
   - AppIcon.co
   - IconGenerator.app

### Quick Design Idea:
- White/light background
- Burgundy heart (#8B1538) in center
- Simple "M" letterform overlay
- Rounded square shape

## T-Shirt Logo

### File Created:
- `mobile/assets/mulligan-logo.svg` - SVG format (scalable for printing)

### Design:
- "Mulligan 🤍" text in burgundy (#8B1538)
- Can be resized for any shirt size
- White text on dark shirt, or dark text on light shirt

### To Use:
1. Open the SVG in any design tool (Figma, Illustrator, etc.)
2. Export as high-res PNG/JPG for printing
3. Send to your t-shirt printer

### Alternative Formats Needed:
- **Vector**: SVG or EPS (for scaling)
- **High-Res PNG**: 300 DPI minimum for printing
- **Inverted version**: White text for dark shirts
