2. APP PURPOSE AND VALUE — HOW MULLIGAN IS DIFFERENT
Mulligan is a dating app for adults 18+ in Southern Oregon. It is NOT a clone swipe app. Differentiation: (1) Southern Oregon region lock — local, meetable matches; (2) Mulligan TOKENS — each connect costs a token (intentional, not unlimited swiping); (3) rich profiles (interests, dealbreakers, lifestyle); (4) SOBER CIRCLE tab — separate matching pool for sober/sober-curious users; (5) LIVE DATES tab — sign up for curated in-person dating events; (6) in-match messaging plus icebreaker games and date-planning tools. Audience: adults 18+ near Southern Oregon seeking intentional local dating.

3. INSTRUCTIONS AND TEST CREDENTIALS
No shared test account. Please Sign Up with your own phone number (SMS code). Suggested path: sign up → create profile → Connect (browse, tap Connect & Match — uses 1 token) → Sober tab (pick sober level, explore pool) → Live tab (view/sign up for event) → Matches (chat) → Settings (tokens, privacy, Delete Account under Danger Zone). Main tabs: Connect, Matches, Live, Sober, Profile, Settings.

4. EXTERNAL SERVICES
Backend: Node/Express on Render (mulligan-backend.onrender.com). Auth: phone + SMS. IAP: RevenueCat + Apple IAP for Mulligan tokens. DB: PostgreSQL. Push: Expo. Location: Southern Oregon eligibility check. Optional OpenAI for some prompts (fallbacks if unavailable).

5. REGIONAL DIFFERENCES
Restricted to Southern Oregon, USA. Outside region: cannot browse/match; message explains app unavailable. Same account/profile/IAP/messaging/report/block behavior inside the region.

6. REGULATED INDUSTRY
Dating/social app, adults 18+ only. Privacy Policy and Child Safety/CSAE policy linked in app. No other regulated services.
