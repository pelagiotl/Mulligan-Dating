2. RESPONSE TO GUIDELINE 4.3(b) — HOW MULLIGAN IS DIFFERENT
Mulligan is NOT a generic swipe clone. It is an intentional dating app for adults 18+ in Southern Oregon, built around authenticity and real-life connection:

(1) Mandatory 10–15 second video intro during onboarding — personality and voice before matching.
(2) Live Dates tab — curated in-person speed-dating events with in-app signup.
(3) Sober Circle tab — separate matching pool for sober and sober-curious users (levels: Newly Sober, 1 Year+, 5 Years+, Sober-Curious).
(4) Post-date reflection with mutual reveal — private prompts after a date; positive feedback is revealed only if both want a second date.
(5) Token-based Connect — limited curated connects per week, not infinite swiping.
(6) Smart Date Planner — local Southern Oregon date ideas tailored to each match.

Main tabs: Connect · Matches · Live · Sober · Profile · Settings.

4. EXTERNAL SERVICES
Backend: Node/Express on Render (mulligan-backend.onrender.com). Auth: phone + SMS. IAP: RevenueCat + Apple IAP (Mulligan tokens). DB: PostgreSQL. Push: Expo. Location: Southern Oregon eligibility. Optional OpenAI for some prompts (static fallbacks if unavailable).

5. REGIONAL DIFFERENCES
Southern Oregon, USA only. Outside region: cannot browse/match; in-app message explains unavailability. Account, profile, IAP, messaging, report, and block work the same inside the region.
